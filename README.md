## 📌 精选项目 / Selected Projects

- **[OneNeuralNetwork](https://github.com/matrix97317/OneNeuralNetwork)** — 中文：跨芯片平台的算子集合与统一神经网络库，后端基于 TVM / Triton 等深度学习编译器，目标是在异构芯片上运行 OpenMMLab、Detectron、DeepSpeed、Megatron-LM 等上层应用。  
  *EN: A cross-chip operator collection and unified neural network library, built on DL compiler backends (TVM, Triton) to run OpenMMLab / Detectron / DeepSpeed / Megatron-LM on heterogeneous platforms.*

- **[OneTensor](https://github.com/matrix97317/OneTensor)** — 中文：极简 Tensor 库，专为手写 CUDA kernel 时快速构造测试数据而设计，支持 Tensor 创建、Host/Device 数据搬运、npy/npz 加载与数据显示，相比 PyTorch/Cute 更轻量。  
  *EN: A minimal Tensor library for quickly creating test data when writing CUDA kernels — Tensor creation, host/device transfer, npy/npz loading, and data view, lighter than PyTorch/Cute.*

- **[RLink](https://github.com/matrix97317/RLink)** — 中文：面向分布式强化学习系统的轻量高性能通信层，解耦 Actor 采样与 Learner 训练，优化轨迹与模型参数的传输延迟。  
  *EN: A lightweight, high-performance communication layer for distributed RL, decoupling Actor sampling from Learner training and optimizing trajectory/model-parameter transfer latency.*

- **[pig-solver](https://github.com/matrix97317/pig-solver)** — 中文：一个 tiny 版本的 PyTorch。  
  *EN: A tiny PyTorch — a minimal deep learning framework built for learning and hacking.*

- **[UniRobot](https://github.com/matrix97317/UniRobot)** — 中文：一个具备训练和真机部署的全栈 robot 工程框架。  
  *EN: A full-stack robotics engineering framework covering both training and real-world deployment.*
